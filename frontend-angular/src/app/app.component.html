Task 5 Deliverable

🚀 Scaling Architecture Blueprint (5,000 Gig Workers)

Production architecture designed to handle 5,000 concurrent gig workers submitting audio on the same day without downtime:

💥 What Breaks First

• Synchronous Audio CPU: 5,000 ffmpeg/numpy threads crash server with 504 timeouts.

• Network Ingress: 2.5 Gbps burst upload saturates VM network.

• MySQL Pool: 5,000 concurrent connections overwhelm MySQL max 150 limit.

🛠️ Production Redesign

• Direct-to-S3 Pre-signed URLs: Zero audio stream bytes touch backend server CPU/RAM.

• Amazon SQS Queue Decoupling: Buffers 10,000+ burst submissions in milliseconds.

• Auto-Scaling Lambda Processors: Scales horizontally from 2 to 100+ audio workers.

• Amazon RDS Proxy + Aurora MySQL: Multiplexes thousands of connections into steady pool.

💰 Estimated AWS Monthly Cost

• S3 Storage & API Calls: $5.05 / mo

• AWS Lambda Audio Extraction: $1.35 / mo

• Amazon RDS MySQL + RDS Proxy: $67.00 / mo

• CloudFront CDN & Route 53: $3.50 / mo

• TOTAL ESTIMATED COST: ~$97.90 / month
